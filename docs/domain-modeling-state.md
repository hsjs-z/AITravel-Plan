## 已定型的决策

### 第 1 轮（根决策；全部按推荐 + 3 条修正）

1. 方案与行程是同一实体：AI 产物直接落为草稿行程。
2. 资源分可交易与内容两类；景点是内容，交易发生在门票上。
3. 订单是联合预订的聚合根，「预订」不是独立实体。
4. 支付成功即自动进入「已确认」；CONFIRMED 为预留状态位（ADR-0001）。
5. v1 资源平台自营，不建模商家，不预留商家字段。
6. 库存单元 = 资源 + 日期 + 规格（ADR-0002）。
7. 预算为行程级总额，以人民币计价。
8. 已创建/已预订/已支付可取消，取消自动全额退款；已确认后不开放取消（ADR-0003）。
9. 对账 = 内部金额与状态一致性校验，加上重复/乱序通知去重。
10. 行程变更通知仅针对已存在订单的行程。
11. 未支付占用 15 分钟自动释放（可配置）。
12. 只有一种账号概念：用户。

### 第 2 轮（全部按推荐）

1. 无订单的行程可编辑（退回草稿）；产生订单后行程只读。
2. 一键预订默认全选，允许取消勾选子集；子集内要么全成、要么全补偿。
3. 规划任务重试只保留最后成功的草稿行程。
4. 订单明细保存下单时的价格快照，后续改价不影响已有订单。
5. 资源下架不影响已产生的订单，只阻止新预订与推荐。
6. 站内信是唯一必达渠道，邮件为可选副本；去重以业务事件为粒度。
7. 同一行程同一时间最多一个「进行中」的联合预订。
8. 预估预算 = 行程内资源价格汇总（含弹性提示）。
9. 一个行程项至多绑定一个资源，允许纯文本（自由活动）项。

### 第 3 轮（Q1 修正后其余按推荐）

1. 一键预订默认数量：门票/车票 = 出行人数（张），酒店 = 1 间；均可逐项调整，下限为 1；
   房型的可住人数只是资源属性，不决定默认间数。
2. v1 仅支持单一目的地（城市或省级区域），多目的地/环线延后。
3. 输入校验：目的地必填；天数 1–30；人数 1–20；预算为正整数元。
4. 订单取消或失败后，行程回到「行程确认」，可再次预订。
5. 失败与取消的订单保留为历史记录，不销毁行程。
6. 售罄（库存为 0，可补货恢复）与下架（整体停止展示与新预订）是两个概念。
7. 下单后整份行程只读，直至该订单结束（ADR-0004）。
